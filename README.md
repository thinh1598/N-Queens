# N-Queens SAT & ILP/CP Solver
Bài tập lớn số 1 - Các vấn đề hiện đại KHMT.
Mã nguồn giải quyết N-Queens bằng PySAT (Glucose3) và các công cụ ILP/CP (Gurobi, CPLEX, CP-SAT).

## Cách chạy thực nghiệm
1. Cài đặt thư viện: `pip install python-sat ortools gurobipy cplex docplex`
2. Khởi chạy đo lường: `python run_experiments.py`
